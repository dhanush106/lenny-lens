# Phase 0: Project Non-Goals

## 1. Explicit non-goals
The following items are intentionally out of scope for the initial build:
- Authentication or user login flows
- Multi-tenant enterprise administration
- Billing, subscriptions, or account management
- Advanced analytics and dashboards
- Fine-tuning of foundation models
- Real-time collaborative editing
- Mobile app development
- Large-scale production distributed hosting
- Full enterprise compliance and audit tooling

## 2. Why these are excluded
These features are useful in a production product, but they are not necessary to validate the core assignment outcomes. The project should first prove the end-to-end value of grounded transcript search, generation, and safe artifact output.

## 3. Strategic trade-off
The team should optimize for a focused, demonstrable system that works reliably in a local environment over a broad but shallow product surface.
